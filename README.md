# DSA — Frontend

Interface web desenvolvida em **JavaScript, HTML5 e CSS3**, responsável pela interação do usuário com o sistema DSA, permitindo o gerenciamento de produtos, vendedores e controle de faltas.

## Funcionalidades

- **Gerenciamento de Produtos:** Cadastro, consulta, edição e exclusão de produtos.
- **Gerenciamento de Vendedores:** Visualização e administração dos vendedores.
- **Controle de Faltas:** Registro, consulta e atualização das faltas de produtos.
- **Interface Web:** Navegação entre as funcionalidades do sistema.
- **Integração com API REST:** Comunicação com o backend desenvolvido em Go.

## Tecnologias Utilizadas

- **JavaScript:** Implementação das funcionalidades e interações.
- **HTML5:** Estrutura das páginas.
- **CSS3:** Estilização e organização visual.
- **API REST:** Comunicação com o backend.

## Como Executar

1. Clone ou baixe o repositório.
2. Configure o endereço da API backend, conforme a implementação.
3. Execute o frontend utilizando o ambiente de desenvolvimento configurado no projeto.
4. Acesse a aplicação pelo navegador.
